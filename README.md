# Stack vs Debt

Holding crypto or stocks while paying credit card interest? This free calculator shows how long your stack lasts,
the price you'd need to clear your debt, and how selling now, selling monthly, or waiting compare in falling, flat and rising markets.

- Live: https://akadannyhugo.github.io/stack-vs-debt/
- No login. Everything you type stays in your browser (localStorage).
- Live crypto prices come from Coinbase's public spot price endpoint (no key).
- **Not financial advice.** It's a calculator for the numbers you enter.

## Run locally
```
npm install
npm test
npm run dev
```
`npm run build` outputs to `dist/` with base `/stack-vs-debt/` (set `BASE_PATH=/` for a root domain).
The site is published from the `gh-pages` branch.
